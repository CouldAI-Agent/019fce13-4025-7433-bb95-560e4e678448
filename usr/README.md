# Soluciones - Presentación Profesional y Onboarding

Una aplicación Flutter que incluye un flujo de onboarding elegante y formal, diseñado para presentaciones profesionales. Cuenta con la identidad visual de "Soluciones" y guía al usuario a través de una serie de diapositivas interactivas antes de acceder al contenido principal de la aplicación.

## Características
- **Onboarding Profesional**: Un carrusel de diapositivas formales e interactivas.
- **Identidad Visual**: Integración del concepto y logo de "Soluciones".
- **Diseño Responsivo**: Adaptado para móviles, tablets, escritorio y web, asegurando que la presentación se vea impecable en cualquier dispositivo.
- **Navegación Fluida**: Transiciones suaves entre las tarjetas de presentación y la pantalla principal.

## Flujos Principales
1. **Inicio de la App**: Se muestra la pantalla de Onboarding.
2. **Navegación de Diapositivas**: El usuario desliza o usa los botones para avanzar por las características de "Soluciones".
3. **Acceso**: Al finalizar el recorrido, el usuario ingresa a la vista principal de la plataforma.

## Pila Tecnológica (Tech Stack)
- [Flutter](https://flutter.dev/) - Framework de desarrollo UI multiplataforma.
- Dart - Lenguaje de programación.

## Instrucciones de Ejecución
Para ejecutar este proyecto de forma local:

1. Asegúrate de tener Flutter instalado y configurado.
2. Clona este repositorio.
3. Ejecuta `flutter pub get` para obtener las dependencias.
4. Ejecuta `flutter run` para iniciar la aplicación en tu dispositivo o emulador preferido.
